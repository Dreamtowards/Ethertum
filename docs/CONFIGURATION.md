# 配置加载与错误处理

服务端配置位于工作目录的 `server.settings.json`。文件不存在时使用默认值；坏 JSON、非法字段及读取失败会报告具体文件和原因，并以失败状态退出，不启动默认游戏端口，也不覆盖坏文件。

```json
{
  "port": 4060,
  "num_player_limit": 64,
  "motd": "An Ethertum Server",
  "status_addr": "0.0.0.0:8001"
}
```

游戏端口必须非零；人数限制为 1–64，与网络玩家列表校验共用上限。旧文件若配置 80 人，需要改到支持范围；不再静默忽略该配置。缺少字段时补默认值。`status_addr` 可设为 `null` 关闭可选的 HTTP 状态接口，指定地址时端口必须非零。

游戏 UDP 端口占用或传输初始化失败会记录原因并请求失败退出。HTTP 状态端口绑定失败仅关闭该接口并警告。状态响应报告真实协议版本与配置人数上限；当前接口仅提供状态，并非已实现远程管理权限或账号认证。

退出时配置序列化/写入失败会记录错误，不再 unwrap。当前文件写入仍非原子替换；原子保存与崩溃一致性由 PLAN 的 T14 处理。

## 客户端

客户端读取工作目录的 `client.settings.json`。文件缺失使用默认值；坏 JSON、读取失败或非法字段会回退默认值，并在主菜单和设置页显示原因。该次运行禁止覆盖原文件；修复或移走原文件并重启后恢复保存。

- FOV：10–170，必须有限；HUD padding：0–48，必须有限。
- 用户名：最多 64 UTF-8 字节，不得全空白或包含控制字符；与网络校验共用规则。
- 水平区块距离：0–16；垂直距离：0–8。`(-1,-1)` 是唯一禁用组合，设置页提供统一开关，不再分别选择 -1。

加载、保存和连接前均检查字段；保存失败只报告错误，连接配置非法或传输初始化失败则显示断线原因，不安装半初始化的客户端资源。DNS 仍为同步解析，后续 T06 再迁移到后台。
