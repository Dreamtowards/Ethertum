# 网络输入与命令边界

客户端和服务端只处理通过 `src/net/validation.rs` 解码及字段校验的消息。损坏包或无效字段会断开对应连接；登录后的普通命令语法错误只返回聊天提示，连接继续使用。

## 解码与兼容性

- 单条应用消息最多 64 KiB，解码器也有相同读取预算。完整的 4096 个 `CellData` 区块消息仍能传输。
- 显式使用 bincode 1.3 的定长整数编码，与现有 `bincode::serialize` 一致；枚举顺序、字段结构和 `PROTOCOL_ID` 均未改变。
- 拒绝截断数据、未知枚举、尾随字节和伪造长度。读取预算限制解码消耗，不替代 Renet 的分片缓存或流量限速。

## 字段与状态

- 用户名最多 64 UTF-8 字节，不得全为空白或包含控制字符；客户端聊天输入最多 1024 字节。
- 玩家坐标必须有限，各轴绝对值最多 1,000,000；网络区块坐标也采用此范围，且必须对齐到 16。此边界为原型的数值保护范围。
- 区块体素列表最多 4096 项，每个局部索引必须在 `0..4096`。校验发生在写入区块之前，保留负区块坐标语义。
- 客户端请求的水平加载距离为 `0..=16`，垂直距离为 `0..=8`；保留 `(-1, -1)` 禁用加载的现有状态。
- 不兼容握手、未登录时发送游戏消息、重复登录及重复用户名会被拒绝并断开连接，不再继续处理该连接的后续消息。
- 现有客户端可直接发送 Login，并不要求新增握手步骤。登录仍是原型，没有实现真实认证、权限或服务端权威地形编辑。

## 命令

目前支持 `/time set <0..=1>`，时间是一天的归一化比例。参数必须完整且数值有限；空命令、不闭合引号、未知命令、缺失或多余参数都返回错误提示，不执行世界时间广播。

登录时移除了主循环中的模拟等待，并停止记录 access token 和原始连接用户数据。客户端计算 Pong 时间差时采用饱和运算，避免异常时间戳溢出。HTTP 状态响应的发送失败也只记录错误，不 panic。

## 回归测试

`src/net/tests.rs` 覆盖损坏包、超大包、伪造字符串/数组长度、异常数值、越界局部索引、负坐标完整区块，以及错误命令。测试还使用 Renet 本地连接运行实际 `server_sys`：验证错误命令之后仍能处理正常消息、拒绝非法状态，以及断开一个异常客户端后继续服务其他客户端。

2026-10-11 验证环境为 Windows、Bevy 0.19.1、RTX 4070 Laptop / Vulkan：

- `cargo check --workspace --all-targets --locked --offline` 通过。
- `cargo test --workspace --locked --offline` 全部 24 个测试通过，含 7 个新增网络测试。
- `cargo clippy --workspace --all-targets --locked --offline` 通过，仍有仓库原有警告。
- 两个实际客户端冒烟测试均正常退出：登录、位置同步、跨区块移动与编辑、碰撞、断线清理、同名重新进入均通过。
- 全仓格式检查仍存在原有差异；本次新增及格式化的四个网络文件独立格式检查通过。未升级依赖或修改锁文件。

异常包及命令用本地 Renet 消息队列进行确定性测试；未进行公网恶意流量压测。现有 `ChunkDel` 未实现分支仍会输出错误日志，本轮没有实现区块删除同步或正式认证。
