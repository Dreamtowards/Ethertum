# Local OBJ loader port

Based on `bevy_obj` 0.19.0 by AmionSky, from the cached crates.io package.
Source: https://github.com/AmionSky/bevy_obj

This workspace copy targets Bevy 0.20 and preserves the upstream mesh and
scene loading features. The upstream MIT and Apache-2.0 licenses are included.
The port is under verification; it is not an upstream Bevy 0.20 release.
